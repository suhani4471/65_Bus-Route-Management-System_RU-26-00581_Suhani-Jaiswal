# 65_Bus-Route-Management-System_RU-26-00581_Suhani-Jaiswal
A Python CLI Bus Route Management System modeling an intercity bus network as a weighted graph. Uses Breadth-First Search (BFS) with deque to find routes with the fewest stops between cities, check stop connections, handle disconnected routes, and calculate total travel distance and ticket fares at Rs. 1.50/km.
